# SushiSort-3.3.5

A bag and bank sorting addon for **World of Warcraft 3.3.5a**

Originally created by the guildies of **\<Sushi Regular\>** on US-Draka.

---

## Features
 
- **Sorts your bags** — organises items by quality, class, subclass, and name
- **Sorts your bank** — same sorting logic applied to your bank slots
- **Sorts your guild bank** — sorts the currently open guild bank tab
- **Per-bag checkboxes** — each bag has a checkbox so you can choose which bags to include in a sort

---
## What's new

- **Sorts smallest stack first** — so you don't end up with multiple partial stacks when crafting, using reagent buffs etc.
- **Combines partial stacks** — before sorting, merges split stacks of the same item into full stacks automatically
- **Persistent checkbox states** — your checkbox preferences are remembered per character across sessions

---

## Installation
 
1. Download or clone this repository
2. Copy the `SushiSort` folder into your addons directory:
   ```
   World of Warcraft/Interface/AddOns/SushiSort/
   ```
